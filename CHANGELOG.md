## [1.0.0] - 2026-08-04

### Added
- **Core System Framework**:
  - Fantasy race/species trait hierarchy (Elves, Dwarves, Orcs, Undead, Celestial, Fiend).
  - Magic power resource tracking system with dynamic regeneration based on learning, traits, and holy sites.

- **Event Chains**:
  - `rsf_magic_study_events.txt`: Magic apprenticeship and spell discovery event chains.
  - `rsf_artifact_crafting_events.txt`: Enchanting and magical artifact creation decisions and event flows.

- **GUI & UI Elements**:
  - Magic spellbook window overview in custom GUI (`gui/window_spellbook.gui`).
  - Mana pool status display added to top character overview bar.

- **Localization**:
  - Full English (`english`) localization support across traits, decisions, events, and UI elements.

- **Graphics & Assets**:
  - Icon sets for magical traits and school specs (`gfx/interface/icons/traits/`).
  - Event background illustrations for arcane academies and ritual sites.
